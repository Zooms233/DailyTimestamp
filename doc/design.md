# 时间戳记录工具 · MVP 前端设计

> 用途：生活中不间断地为每个事件打时间戳，回顾时了解自己的时间分配。
> 本设计为最小可行性（MVP）方案：**一行代码不写多余功能**，先跑通"打卡 → 记录 → 回看"闭环。

---

## 1. MVP 范围

### 做（本轮实现）
| 能力 | 说明 |
|---|---|
| 打卡 | 一键标记"现在开始做什么"，自动结束上一个事件 → 时间线**不间断** |
| 今日时间轴 | 按时间顺序列出今日事件及每段时长，进行中的事件高亮 |
| 按日统计 | 每天各标签累计时长 + 占比条形图；月历条（收缩周条/展开整月）点选任意日期回看历史 |
| 数据导出 | 统计页右上角导出 JSON 快照：Windows 直存下载目录，Android 走系统分享面板（备份/恢复流程见 doc/backup.md） |
| 标签 | 分类管理页：默认 12 个，可添加/删除/排序（首页右上角 ⚙ 进入） |
| 备注 | 打卡时可选填，随事件存储，时间轴上小字展示 |
| 本地存储 | 事件数据落盘为 JSON 文件，重启不丢 |

### 不做（留到 V2）
- 完整事件编辑（时间/删除）、撤销——已支持修改事件（类别+备注，复用打卡弹窗）、与上一个合并、拆分事件（交互见 doc/pages.md 第 1 节）
- 周/月/年统计、日历视图、图表库
- 提醒、通知、云同步、多设备

## 2. 信息架构

```
App
├─ Tab1 打卡页（HomePage）   ← 默认页，90% 时间停留在这
│    ├─ 进行中事件卡片（固定底部）
│    ├─ 大按钮「记录新事件」 → 弹出 PunchSheet
│    ├─ 今日时间轴列表（主视区，可滚动）
│    └─ 右上角 ⚙ → 分类管理页（LabelsPage，独立路由）
│         ├─ 添加 / 删除分类
│         ├─ 点色块换色（主色板弹窗，持久化 colors 字段）
│         └─ [↑]/[↓] 顺序调整（即打卡弹窗显示顺序）
└─ Tab2 统计页（StatsPage）
     ├─ 月历条：默认收缩一周（周一起始），可展开整月；点日期切换统计日
     ├─ 当日按标签时长 + 占比条形
     ├─ 未记录时段（空档）提示
     ├─ 右上角 ↑ 导出 JSON 快照（Windows 直存下载目录 / Android 分享面板）
     └─ 日期切换统一经月历条；切回统计 Tab 自动回今日
```

技术要点：单页双 Tab，无路由；分类管理页用 `Navigator.push` 独立路由；`setState` + 内存中事件列表，无需状态管理库。

## 4. 核心交互规则（不间断时间戳）

```
[点击 记录新事件] ──► 弹窗选择标签
                        │
                        ▼
     存在进行中事件？ ──否──► 新事件 startAt = 现在
        │是
        ▼
   旧事件 endAt = 现在 ──► 新事件 startAt = 现在
```

- 规则 1：**任意时刻至多一个进行中事件**。
- 规则 2：新事件开始 = 旧事件结束，时间线天然连续、无重叠、无缝隙。
- 规则 3：事件可**修改事件**（类别+备注，复用打卡弹窗，见 doc/pages.md 第 1/2 节）、**与上一个合并**、**拆分事件**（防误触/修正手段）；不可修改起止时间，不可单独删除（V2）。
- 规则 4：App 冷启动时恢复"进行中"状态（进行中事件标为 endAt=null，可跨天持续）。

## 5. 数据模型

```json
{
  "labels": ["睡眠", "清洁", "吃饭", "行路", "学习", "运动", "代码", "阅读", "游戏", "碎片信息流", "总结", "其他"],  // 有序分类，顺序=打卡弹窗显示顺序
  "colors": { "碎片信息流": -10720169 },  // 用户改过的分类色（ARGB int）；缺失时按语义表+调色板确定性指派
  "events": [
    {
      "id": "1719983520000_ab12",      // 毫秒时间戳 + 随机后缀
      "label": "阅读",
      "startAt": 1719983520000,        // 开始，毫秒 epoch
      "endAt": 1719985920000,          // 结束；null = 进行中
      "note": "《原子习惯》第 3 章"     // 备注；可空（null）
    }
  ]
}
```

- 纯 Dart 类 `TimestampEvent`，手写 toJson/fromJson，零依赖。
- 时区一律用本地时间；跨天事件按"结束日"归属统计，进行中事件在统计中截止到"现在"。
- `labels` 缺失时（旧数据）回退为默认 12 分类；删除分类不影响历史事件（事件里仍存 label 字符串）与统计。

## 6. 存储与技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 存储 | 单文件 `events.json`，整文件读写。统一存公共文档目录 **`Documents/DailyTimestamp/`**（Android = `/storage/emulated/0/Documents/DailyTimestamp/`，Windows = 文档目录/DailyTimestamp），需"所有文件访问"授权（MANAGE_EXTERNAL_STORAGE，统计页/启动权限页引导，未授权阻塞启动）；数据文件与自动备份同目录，文件管理器直接可见，备份/迁移=拷文件，卸载/重装数据不丢（恢复=把 events.json 拷回同目录） | 卸载时系统清 `Android/data`（曾事故 2026-09-06），公共 Documents 不受影响；不做其他路径回退（未授权即退），路径唯一简单可预期 |
| 写盘 | **原子写 + 防抖串行**：改动后 150ms 防抖合并写；写盘队列串行化（并发写同一 tmp 有损坏风险）；退后台/失焦/关窗即 `flush()` 落盘 | 防断电/崩溃导致 JSON 半写损坏；防连续快速打卡多次全量写盘；防并发 rename 竞争丢文件 |
| 自动存档 | 每次记录新事件触发：**公共下载目录**（Android `/storage/emulated/0/Download`，卸载不清、文件管理器可见、无需权限；桌面端 = 下载目录/DailyTimestamp/；公共下载不可写时回退应用专属目录并警示）每日一份 `DailyTimestamp_backup_YYYYMMDD.json`（当天覆盖），距上次 ≥1h 才重写；仅清理本前缀文件，按文件名日期保留最近 9 份；开关持久化在 events.json 顶层 `settings.autoBackup`（默认开）；设置弹窗（统计页 ⚙）可开关/看位置/立即备份/看备份列表 | 卸载时系统会清 `Android/data` 与 MediaStore 中归属本应用的多媒体文件，但公共下载文件保留（浏览器下载同理）；高频打卡靠每日+1h 节流避免 9 份全是当天；恢复窗口 ≤1h |
| JSON 解析 | `compute()` 后台 isolate 解析，主线程零阻塞 | 万级事件（1.5MB）同步解析在 Android 弱机可致首帧白屏 200-500ms |
| 依赖 | `path_provider` + `share_plus`（均为官方一线包） | path_provider 取应用/下载/临时目录；share_plus 供 Android 导出时调系统分享面板；其余全部 Flutter SDK |
| 状态 | `setState` + 单例 `EventStore` | 事件流单一，状态简单 |
| 平台 | Android + Windows | 手机随身打点；Windows 本机调试回看。Web 需要 localStorage 存储适配且与桌面调试重复，V2 再议 |
| 字体 | 思源黑体（直接指定系统字体名，不打包） | 打包自定义字体与 MaterialIcons 在 Windows 渲染冲突（霞鹜文楷、思源黑体两次复现图标方块），改用 `fontFamily: 'Source Han Sans SC'` 直接指定：Windows 本机已装命中；Android 无此字体名时回退默认中文（Noto Sans CJK，与思源同源），效果一致 |
| 时间格式化 | 手写 `HH:mm` / `x 小时 y 分` 工具函数 | 不用 intl，一个函数 10 行 |
| Android 构建 | `flutter build apk --release --target-platform android-arm64`：只打 arm64，APK 46.8MB → ~15MB（默认 fat 包含三架构引擎拷贝，自用只装 arm64）；需要 x86_64 模拟器时临时用默认命令另打 |

## 8. 验收用例（人工核验）

1. 首次打开 → 无进行中事件，时间轴为空，出现"记录新事件"大按钮。
2. 点大按钮 → 弹窗出现；在备注框填《原子习惯》后点「阅读」→ 弹窗关闭，卡片显示"进行中：阅读《原子习惯》"（备注小字），时间轴出现 `现在-现在 阅读 进行中 ▶`。
3. 隔几分钟点「工作」（备注留空）→ 阅读行变为 `开始-结束` 且时长正确，无备注不再显示小字；两条时间无缝衔接。
4. 杀进程重启 → 进行中事件仍为进行中，历史数据完整。
5. 切到统计页 → 今日百分比合计 = 100%（含空档），条形长度与占比一致。
6. 月历跳到无记录的一天 → 显示"这一天没有记录"；周条/月历上有记录的日期带圆点。
7. 首页右上角 ⚙ → 分类管理：添加"冥想" → 弹窗出现该标签；上移/下移顺序在弹窗同步变化；删除"冥想" → 弹窗消失该标签，但历史记录与统计仍含"冥想"。
8. 分类管理重启后顺序、增删结果保持。
9. 各分类有独立颜色：打卡弹窗 chip、时间轴行左侧色条、进行中圆点、统计条形同色一致；分类管理页点色块换色后以上各处即时同步。
10. 点击今日时间轴某行（如误触产生的「其他」）→ 选「修改事件」→ 弹窗预填当前类别（打勾）与备注，文案「当时在做什么？」→ 点正确类别保存，可同时改备注，统计随之变化。
11. 点击事件行 → 选「与上一个合并」→ **弹出确认框**（显示双方类别与时长、说明合并后保留上一事件类别）→ 取消则无变化；确认后两条变一条（时长相加），备注合并；第一条事件合并时提示"已是第一个事件，无法合并"。
12. 点击事件行 → 选「拆分事件」→ 底部弹窗：**时/分双滚轮**（小时列表 0..maxH 为事件范围上限；末小时分钟受剩余分钟余量限制，超限自动收敛）+ 大字实时时刻 +「在 10:34 拆分」按钮 → 点按钮即拆为两段（同类别同备注）；进行中事件拆分后第二段仍为进行中；事件短于 2 分钟提示无法拆分。
13. 统计页月历：默认收缩为统计日所在周；点周条日期即切日；点月份标题展开整月，[<]/[>] 翻月（不改统计日），点任意日期切日且月历保持展开；从打卡页切回统计页自动回今日并收起月历。
14. 统计页右上角导出 → Windows 直存下载目录并提示文件名；Android 弹出系统分享面板（备份数据）。
