# 打卡页 HomePage

`pages/home_page.dart`。默认首页；时间轴主视区可滚动，进行中卡片与打卡按钮固定底部。

## Widget 树

```text
HomePage（10s 定时刷新进行中时长）
├── AppBar
│   ├── [<] 上一日 · 今日/日期 · [>] 下一日（今日时禁用，不能晚于今日）
│   └── [⚙] → LabelsPage（push 独立路由）
├── ListView（时间轴主视区）
│   ├── 标题「今日时间轴（n 个事件）」；空态文案
│   └── TimelineRow × n → 点击弹操作单
├── 底部固定区
│   ├── _OngoingCard          # 进行中卡片；无进行中时占位提示
│   └── 「记录新事件」→ PunchSheet
└── 弹层
    ├── PunchSheet            # 打卡 / 修改事件（widgets/punch_sheet.dart）
    ├── 合并确认 AlertDialog
    └── 拆分弹窗 → TimeOffsetPicker（widgets/time_offset_picker.dart）
```

## TimelineRow（widgets/timeline_row.dart）

- 行 = `开始-结束 分类色条 标签 备注 时长`，进行中带 `▶`。
- 跨天标注：昨日 `昨HH:MM`、次日 `明HH:MM`，时长按该日内占用计。
- 统计页只读复用（不响应点击）。

## PunchSheet（widgets/punch_sheet.dart）

- 点任一标签立即记录并关闭，同时提交备注（可空，随事件存储、小字展示、不参与统计）。
- 修改模式：标题「当时在做什么？」，预填备注、当前类别打勾高亮；点标签即保存。
- 无取消按钮：关闭即不改变任何状态；旧事件随新打卡自动结束（设计意图）。

## 交互要点

- 行操作单：修改事件 / 与上一个合并（二次确认，保留上一事件类别，备注合并）/ 拆分事件。
- 合并按全局时间线定位上一条，可跨日并入前一天末尾；第一条事件提示无法合并。
- 非今日查看：底部打卡按钮与进行中卡片仍是"现在"语境；历史日行操作同样可用。
- 进行中卡片开始时刻跨天标注：昨日「昨HH:MM」，更早「MM-DD HH:MM」。

## 拆分弹窗（TimeOffsetPicker）

- 小时滚轮列出时段覆盖的全部时钟小时（如 10:04~12:04 → 10/11/12 时，跨天按 24 回绕）；分钟滚轮循环显示真实分钟。
- 可拆时刻 = 开始后 1 分钟 ~ 结束前 1 分钟：滑分钟越界弹回停住；切小时时非法分钟就近钳制。
- 大字实时时刻 +「在 HH:MM 拆分」确认；拆为同类别同备注两段，进行中事件拆后第二段仍进行中。
- 事件短于 2 分钟提示无法拆分。行为测试：`app/test/time_offset_picker_test.dart`。
