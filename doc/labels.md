# 分类管理页 LabelsPage

`pages/labels_page.dart`。打卡页右上角 ⚙ 进入，独立路由。

## Widget 树

```text
LabelsPage
├── AppBar「分类管理」
├── 添加行：TextField「新分类名称…」 + [添加]（回车同效）
└── 分类行 × n
    ├── 色块 → 点击弹主色板换色（持久化 colors）
    ├── 分类名
    └── [↑] [↓] [🗑]
```

## 要点

- 添加：重名/空名拒绝。
- 排序：[↑]/[↓] 即打卡弹窗标签显示顺序。
- 默认 12 分类按语义指派颜色（睡眠=indigo、吃饭=orange…），自定义分类取未占用色；换色后弹窗 chip、时间轴色条、进行中圆点、统计条形即时同步。
- 删除：仅从打卡列表移除；历史事件与统计按 label 字符串聚合，不受影响。
- 分类存于 events.json 顶层 `labels`（有序数组）；用户改色存 `colors`。
