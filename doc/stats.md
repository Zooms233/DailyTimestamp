# 统计页 StatsPage

`pages/stats_page.dart`。按日统计时间分配；每分钟自动刷新（进行中占用随"现在"增长）。

## Widget 树

```text
StatsPage
├── AppBar
│   ├── 标题「统计」
│   └── [⚙ 存档] → BackupSettingsSheet · [↑ 导出] → JSON 快照
└── ListView
    ├── 月历条                  # 收缩周条 / 展开整月，随列表滚动
    ├── 摘要行                  # 「日期 · 已记录 x · 未记录 y」，点击切换视图
    ├── 条形视图：_StatRow × n   # 标签 + 占比条形 + 时长 + 百分比；空档固定最后（灰）
    └── 时间线视图：只读 TimelineRow × n
```

`BackupSettingsSheet`（widgets/backup_settings_sheet.dart）：自动存档开关（持久化 `settings.autoBackup`）+ 数据位置 + 立即备份 + 最近备份列表（点击可预览内容）。

## 月历条

- 收缩态（默认）：统计日所在周，周一起始，约 72px。
- 展开态（点月份标题）：整月网格，约 280px；`[<]/[>]` 翻月只改月历不改统计日；非当月格子留空。
- 标记：选中日实心圆白字；有记录日期数字下 2px 圆点；今日未选中的高亮文字。
- 所有日期切换统一经月历；从打卡页切回自动回今日并收起。
- 纯 Flutter 自绘，不引第三方日历库。

## 统计列表

- 按标签聚合当日时长，条形长度 = 占比；空档 = 24h − 已记录，固定排最后。
- 摘要行点击切换：占比条形 ↔ 当日时间线（只读，样式同打卡页）；切日不重置视图模式。
- 无记录显示「这一天没有记录」。
- 右上角导出：Windows 直存下载目录，Android 走系统分享面板。

## 启动权限门（AppGate，main.dart）

```text
┌──────────────────────────────────────┐
│       需要"所有文件访问"权限        │
│  数据保存在公共文档目录             │
│  Documents/DailyTimestamp，        │
│  卸载/重装后不丢失。               │
│      [ ⚙ 去授权 ]                  │
│        退出应用                     │
└──────────────────────────────────────┘
```

- Android 启动探测 Documents/DailyTimestamp 可写性（真实写入+删除探测文件）；不可写则阻塞启动，仅"去授权"与"退出"；从设置页返回自动重检。
- 授权在卸载重装后重置：重装后停在权限页，去授权即无损恢复。
- Windows 无此限制，直接进入。
